Re-Tix

A ticket resale and verification platform that enables users to securely sell, browse, purchase, and transfer unused event tickets through a structured ownership-transfer workflow.

PROBLEM

Unused tickets and insecure peer-to-peer transfers create trust and ownership issues for event buyers and sellers.

SOLUTION

A centralized platform for listing, browsing, buying, and verifying ticket ownership before transfer so that the process is secure and structured.

KEY FEATURES
  • Authentication with JWT and protected routes
  • Ticket CRUD operations and browsing
  • Buying and ownership-transfer workflow
  • Role-based access and backend validation
  • MongoDB relationships and secure transaction flow
  • Verification process preventing unauthorized direct ownership changes
